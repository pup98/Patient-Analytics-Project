# Patient-Analytics-Project
This project replicates a real-world managed care analytics workflow using synthetic patient-level claims data, structured to resemble industry-standard datasets such as IQVIA LAAD, Symphony Claims, and Specialty Pharmacy records commonly leveraged by pharmaceutical Value & Access teams.

The objective is to deliver payer reimbursement insights, analyze drug utilization trends, conduct longitudinal adherence assessments, and generate actionable recommendations that inform payer access and reimbursement strategies. The workflow is intentionally aligned with the operating models of analytics teams at leading pharmaceutical companies, including Amgen, AstraZeneca, and Pfizer.

## Aim and Results
* Created a python script to analyze claims, patients and drug datasets. The data is synthetic and was created to simulate actual datasets used by pharma companies.
* After analysis developed a PowerBI dashboard to visually explain the results.
